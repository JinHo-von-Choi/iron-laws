# 지원 범위 행렬

언어·규칙별로 구현된 것과 시험으로 검증된 것을 구분해 공개한다. **파서가 있다는 사실은 그 규칙이 그 언어에서 검증되었다는 뜻이 아니다.**
이 표는 `iron-laws support`의 출력과 같고, 시험 사례에서 자동으로 센 `src/iron_laws/standards/data/support_fixtures.json`을 근거로 한다.
시험 사례를 바꾸면 `uv run python benchmarks/build_support_manifest.py`로 갱신해야 하며, CI가 최신 여부를 확인한다.
